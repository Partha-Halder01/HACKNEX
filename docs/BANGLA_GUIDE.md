## ১. প্রজেক্টটি কী?

সুন্দরবনের ম্যানগ্রোভ বন বাতাস থেকে প্রচুর কার্বন টেনে নিয়ে মাটি ও গাছে জমা রাখে। একে বলে **"ব্লু কার্বন"**। বন কমলে সেই কার্বন ঝুঁকিতে পড়ে।

এই প্রজেক্ট **উপগ্রহের ছবি** দেখে চারটি প্রশ্নের উত্তর দেয়:

| প্রশ্ন | উত্তর কোথা থেকে |
| :-- | :-- |
| এই জায়গায় কতটা ম্যানগ্রোভ বন আছে? | উপগ্রহের ছবি + মেশিন লার্নিং মডেল |
| সময়ের সঙ্গে বন বেড়েছে না কমেছে? | দুই তারিখের ছবির তুলনা |
| বনে কতটা কার্বন জমা আছে? | বনের এলাকা × আন্তর্জাতিক (IPCC) হিসাব |
| আগামী ৫ বছরে কী হতে পারে? | বর্তমান ধারা থেকে ৩টি সম্ভাব্য চিত্র |

শেষে সব ফল **সহজ বাংলা ও ইংরেজিতে** লেখা হয়, যাতে গ্রাম পঞ্চায়েত, বন দপ্তর বা সাধারণ মানুষ বুঝতে পারেন।

**কোনো লগইন লাগে না।** যে কেউ পেজ খুলে ব্যবহার করতে পারেন।

## ২. এটি কীভাবে কাজ করে? (ধাপে ধাপে)

আপনি মানচিত্রে একটি জায়গা আর দুটি তারিখ বেছে "বিশ্লেষণ চালান" চাপলে পেছনে এই ধাপগুলো চলে:

```
আপনার বাছাই (জায়গা + তারিখ)
        │
        ▼
① উপগ্রহের ছবি সংগ্রহ  ──  Sentinel-2 উপগ্রহ, মেঘ সরানো
        │
        ▼
② মডেলকে শেখানো  ──  CGMD ম্যাপ থেকে "কোনটা ম্যানগ্রোভ" শেখা
        │
        ▼
③ মডেলের পরীক্ষা  ──  না-দেখা বছরে (২০২৩) কতটা ঠিক বলে
        │
        ▼
④ প্রতিটি সময়ের ম্যাপ  ──  শুরু, মাঝের প্রতি বছর, শেষ
        │
        ▼
⑤ পরিবর্তন মাপা  ──  কোথায় বন বেড়েছে, কোথায় কমেছে
        │
        ▼
⑥ কার্বন হিসাব  ──  এলাকা × ২৮৩.১ টন কার্বন/হেক্টর (± ভুলের পরিসর)
        │
        ▼
⑦ ভবিষ্যৎ চিত্র  ──  আগামী ৫ বছরের ৩টি সম্ভাবনা
        │
        ▼
⑧ সহজ ভাষায় সারাংশ  ──  বাংলা + ইংরেজি
```

### ① উপগ্রহের ছবি সংগ্রহ

- ইউরোপের **Sentinel-2** উপগ্রহ প্রতি ৫ দিনে সুন্দরবনের ছবি তোলে। প্রতিটি পিক্সেল ১০ মিটার × ১০ মিটার।
- আপনার বেছে নেওয়া তারিখের আশেপাশের (ডিফল্ট ৯০ দিন) সব ছবি নেওয়া হয়।
- মেঘ আর মেঘের ছায়া সরিয়ে একটি পরিষ্কার "মিলিত ছবি" (composite) বানানো হয়।
- ছবি থেকে ৮টি তথ্য নেওয়া হয়: নীল, সবুজ, লাল, ইনফ্রারেড আলো ইত্যাদি, আর দুটি সূচক:
  - **NDVI** — গাছ কতটা সবুজ ও ঘন
  - **NDWI** — জল কতটা আছে
- এই সব কাজ **Google Earth Engine**-এর সার্ভারে হয়, আপনার কম্পিউটারে নয়।

### ② মডেলকে শেখানো (Random Forest)

- মডেলকে শেখাতে একটি "উত্তরপত্র" লাগে। সেটি হলো **CGMD ম্যাপ**: বিজ্ঞানীদের বানানো বিশ্বের ম্যানগ্রোভ ম্যাপ (১৯৮৪–২০২৩)।
- CGMD প্রতিটি ৩০ মিটার পিক্সেলে বলে দেয় কত শতাংশ জায়গা ম্যানগ্রোভে ঢাকা।
- শেখানোর নিয়ম:
  - **ম্যানগ্রোভ** = ৫০% বা তার বেশি ঢাকা
  - **ম্যানগ্রোভ নয়** = একদম ম্যানগ্রোভ নেই
  - **মাঝামাঝি পিক্সেল** = বাদ, কারণ এগুলো দিয়ে শেখালে মডেল বিভ্রান্ত হয়
- শুধু সেই পিক্সেল নেওয়া হয় যেগুলো ২০১৯–২০২২ চার বছরেই একই রকম ছিল ("স্থির পিক্সেল")।
- বনের কিনারার পিক্সেলও বাদ দেওয়া হয়।
- **Random Forest** মডেলটি আসলে ২০০টি "সিদ্ধান্ত গাছ"-এর একটি দল। প্রতিটি গাছ ভোট দেয়, আর বেশি ভোট যেদিকে, সেটাই উত্তর।

### ③ মডেলের পরীক্ষা

- মডেল ২০২৩ সাল কখনো দেখেনি। তাই ২০২৩-এর ছবিতে তার উত্তর CGMD ২০২৩-এর সঙ্গে মেলানো হয়।
- এ থেকে পাওয়া যায় **নির্ভুলতা** (যেমন ৯৩.৫%), **কাপ্পা** আর **F1** সংখ্যা।
- সঙ্গে আছে **এলাকা যাচাই**: পুরো বেছে নেওয়া এলাকায় মডেলের ম্যানগ্রোভ এলাকা CGMD-এর সঙ্গে মেলে কি না (বিস্তারিত [৮ নম্বর অংশে](#৮-ফলাফল-কতটা-বিশ্বাসযোগ্য-জরুরি-সতর্কতা))।

### ④ প্রতিটি সময়ের ম্যাপ

- প্রতিটি সময়ের ছবিতে মডেল প্রতিটি পিক্সেলকে "ম্যানগ্রোভ" বা "অন্য" বলে দাগায়। সময়গুলো হলো শুরুর তারিখ, মাঝের প্রতিটি বছরের শুকনো মৌসুম (জানুয়ারি–মার্চ), আর শেষের তারিখ।
- প্রতিটি পিক্সেলে মডেল কতটা **নিশ্চিত**, সেটাও দেখায়। ৬০%-এর কম নিশ্চিত হলে সেই পিক্সেল "কম-নিশ্চিত" ধরা হয়।

### ⑤ পরিবর্তন মাপা

শুরু আর শেষের ম্যাপ মিলিয়ে দেখা হয়:

| নাম | মানে |
| :-- | :-- |
| **বৃদ্ধি (gain)** | আগে ম্যানগ্রোভ ছিল না, এখন আছে |
| **ক্ষতি (loss)** | আগে ছিল, এখন নেই |
| **অনিশ্চিত** | পরিবর্তন দেখা গেছে, কিন্তু মডেল নিশ্চিত নয় (গণনায় ধরা হয় না) |
| **স্থির** | দুই সময়েই ম্যানগ্রোভ |

০.৫ হেক্টরের চেয়ে ছোট পরিবর্তনের টুকরো বাদ দেওয়া হয়, কারণ এগুলো সাধারণত ছবির "গোলমাল", আসল পরিবর্তন নয়।

### ⑥ কার্বন হিসাব

- জাতিসংঘের জলবায়ু বিজ্ঞানীদের (**IPCC ২০১৩**) প্রকাশিত মান অনুযায়ী ১ হেক্টর ম্যানগ্রোভে গড়ে থাকে:

| কোথায় | কার্বন (টন/হেক্টর) |
| :-- | --: |
| মাটির উপরে (গাছের কাণ্ড, ডাল, পাতা) | ৭৪.২ |
| মাটির নিচে (শিকড়) | ২৮.৯ |
| মাটিতে (উপরের ১ মিটার) | ১৮০.০ |
| **মোট** | **২৮৩.১** |

- **কার্বন = ম্যানগ্রোভ এলাকা × ২৮৩.১**
- **CO₂ = কার্বন × ৩.৬৭** (এক টন কার্বন বাতাসে গেলে প্রায় ৩.৬৭ টন CO₂ হয়)
- সঙ্গে **± পরিসর** দেওয়া হয় (সাধারণত ±১৮–২০%), কারণ:
  - ২৮৩.১ একটি গড় মান; আসল বনে কমবেশি হয় (±১৮%)
  - এলাকা মাপাতেও কিছু ভুল থাকে (মডেলের নির্ভুলতা থেকে হিসাব)
- ⚠️ এটি **আনুমানিক হিসাব**। এটি কার্বন ক্রেডিট নয়, আর কোনো টাকার মূল্যও দেওয়া হয় না।

### ⑦ ভবিষ্যৎ চিত্র (৩টি সম্ভাবনা)

| চিত্র | মানে |
| :-- | :-- |
| **বর্তমান প্রবণতা** | যেভাবে চলছে সেভাবেই চললে |
| **বেশি ক্ষতি** | ভাঙন বা কাটা দ্বিগুণ হলে |
| **পুনরুদ্ধার** | সুরক্ষা ও নতুন গাছ লাগানো হলে |

প্রতিটির সঙ্গে একটি পরিসর দেওয়া থাকে। **এগুলো পূর্বাভাস নয়,** শুধু "যদি এমন হয়" ধরনের চিত্র।

### ⑧ সহজ ভাষায় সারাংশ

- সব সংখ্যা মিলিয়ে বাংলা ও ইংরেজিতে ছোট অনুচ্ছেদ লেখা হয়।
- **Gemini AI** চালু থাকলে সে লেখাটা আরও সহজ করে সাজাতে পারে। তবে কড়া নিয়ম আছে:
  - Gemini **নিজে কোনো সংখ্যা বানাতে পারে না।**
  - তার লেখার প্রতিটি সংখ্যা হিসাবের সঙ্গে মিলিয়ে দেখা হয়।
  - একটিও মনগড়া সংখ্যা বা "কার্বন ক্রেডিট নিশ্চিত" জাতীয় দাবি থাকলে তার লেখা বাতিল হয়ে সাধারণ টেমপ্লেট দেখানো হয়।

## ৩. প্রজেক্ট চালানো — প্রথমবার সেটআপ

> এটি একবারই করতে হবে। আপনার কম্পিউটারে এগুলো **আগে থেকেই করা আছে**, তাই সরাসরি [৪ নম্বর অংশে](#৪-প্রজেক্ট-চালানো--প্রতিদিন) যেতে পারেন। নতুন কম্পিউটারে লাগলে এই অংশ অনুসরণ করুন।

### যা লাগবে

| সফটওয়্যার | সংস্করণ | কোথা থেকে |
| :-- | :-- | :-- |
| Python | ৩.১১ বা নতুন | python.org |
| Node.js | ২০ বা নতুন | nodejs.org |
| Git (ঐচ্ছিক) | যেকোনো | git-scm.com |

### ধাপ ১ — ব্যাকএন্ড (Python অংশ)

প্রজেক্ট ফোল্ডারে (`HACKNEX`) PowerShell খুলে লিখুন:

```powershell
python -m venv backend\.venv
backend\.venv\Scripts\pip install -r backend\requirements.txt
```

এতে Python-এর জন্য আলাদা একটি পরিবেশ তৈরি হয় আর দরকারি লাইব্রেরি ইনস্টল হয়।

### ধাপ ২ — ফ্রন্টএন্ড (ওয়েবসাইট অংশ)

```powershell
npm install
```

### ধাপ ৩ — চাবি (key) বসানো

১. `backend\.env.example` ফাইলটি কপি করে নাম দিন `backend\.env`।

২. Google Cloud থেকে পাওয়া **Earth Engine service account JSON ফাইলটি** রাখুন এখানে:
```
backend\secrets\gee-service-account.json
```

৩. `backend\.env` খুলে এই লাইনগুলো পূরণ করুন:
```
GEE_ENABLED=true
```

> 🔒 **নিরাপত্তা:** `.env` আর `secrets` ফোল্ডার কখনো GitHub-এ তুলবেন না, কাউকে চ্যাটে পাঠাবেন না। `.gitignore` এগুলো আগে থেকেই আটকে রাখে।

চাবি ছাড়াও প্রজেক্ট চলবে, তবে **ডেমো মোডে** (দেখুন [৭ নম্বর অংশ](#৭-লাইভ-মোড-বনাম-ডেমো-মোড))।

## ৫. ড্যাশবোর্ড ব্যবহার করবেন কীভাবে

### ধাপ ১ — জায়গা বাছুন

তিনভাবে বাছতে পারেন:
- **মানচিত্রে ক্লিক করুন**: সবুজ বিন্দু সেখানে সরে যাবে
- **দ্রুত জায়গা** বোতাম: গোসাবা, সাতজেলিয়া, সজনেখালি
- অক্ষাংশ (lat) আর দ্রাঘিমাংশ (lon) সরাসরি লিখুন

### ধাপ ২ — এলাকার আকার ঠিক করুন

**ব্যাসার্ধ** স্লাইডার দিয়ে ০.৫ থেকে ১০ কিলোমিটার বাছুন। হলুদ বৃত্তের ভেতরের এলাকাই বিশ্লেষণ হবে।

> 💡 ছোট এলাকা (২–৩ কিমি) দ্রুত হয়। বড় এলাকায় বেশি সময় লাগে।

### ধাপ ৩ — তারিখ বাছুন

- **শুরুর তারিখ**: ২০১৯ সালের ১ জানুয়ারি বা তার পরে
- **শেষ তারিখ**: আজ বা তার আগে
- দুটি তারিখের মধ্যে অন্তত **১৮০ দিন** ফারাক থাকতে হবে

> 💡 **সবচেয়ে ভালো তুলনা:** দুটি তারিখই একই মৌসুমে রাখুন, বিশেষ করে **জানুয়ারি–মার্চ** (শুকনো মৌসুম, মেঘ কম)। বর্ষাকালের সঙ্গে শীতকালের তুলনা করলে জোয়ার-ভাটা আর পাতার রঙের পার্থক্যকে ভুল করে "পরিবর্তন" মনে হতে পারে।

### ধাপ ৪ — "বিশ্লেষণ চালান" চাপুন

- **লাইভ মোডে** প্রথমবার **প্রায় ২ মিনিট** লাগে, কারণ Google-এর সার্ভারে মডেল শেখানো আর ছবি বিশ্লেষণ হয়।
- একই জায়গা ও তারিখ আবার চালালে ফল সঙ্গে সঙ্গে আসে (জমা রাখা থাকে)।

### ধাপ ৫ — ফল দেখুন ও শেয়ার করুন

- উপরে **EN / বাংলা** বোতামে ভাষা বদলান
- **WhatsApp** বোতাম: সারাংশ সরাসরি WhatsApp-এ পাঠান
- **প্রিন্ট / PDF**: কাগজে বা PDF হিসেবে রাখুন
- **JSON**: পুরো তথ্য ফাইল হিসেবে নামান
- **লিংক কপি**: এই লিংক খুললে ঠিক একই বিশ্লেষণ আবার খুলবে

### ধাপ ৬ (ঐচ্ছিক) — মাঠ যাচাই

মাঠে গিয়ে কোনো জায়গায় নিজের চোখে ম্যানগ্রোভ আছে কি না দেখলে, নিচের **"মাঠ যাচাই"** ফর্মে লিখে রাখুন। এই তথ্য পরে মডেলের নির্ভুলতা যাচাইয়ে কাজে লাগবে।

## ৮. ফলাফল কতটা বিশ্বাসযোগ্য? (জরুরি সতর্কতা)

আমরা আসল তথ্যে পরীক্ষা করে দেখেছি:

| জায়গা (২ কিমি) | CGMD ২০২৩ | আমাদের মডেল | ফল |
| :-- | --: | --: | :-- |
| সজনেখালি জঙ্গল | ৭০০ হেক্টর | ৬৮৫ হেক্টর | ✅ প্রায় হুবহু মিলেছে (−২%) |
| গোসাবা গ্রাম | ৩ হেক্টর | ২৭ হেক্টর | ❌ প্রায় ৯ গুণ বেশি গুনেছে |

### এর মানে কী?

- **জঙ্গল এলাকায় মডেল খুব ভালো কাজ করে।**
- **গ্রাম এলাকায় মডেল বেশি গোনে।** গ্রামের গাছপালা, বাগান বা ধানখেত উপগ্রহ থেকে দেখতে ম্যানগ্রোভের মতো লাগে, তাই মডেল ভুল করে।
- "নির্ভুলতা ৯৪%" সংখ্যাটা দুই জায়গাতেই প্রায় সমান। তাই শুধু ওই সংখ্যা দেখে এই সমস্যা বোঝা যায় না।

### এজন্যই "এলাকা যাচাই"

প্রতিটি লাইভ বিশ্লেষণে পুরো এলাকার ম্যানগ্রোভ CGMD-এর সঙ্গে মেলানো হয়। অনেক গরমিল হলে:
- "মডেলের নির্ভুলতা" অংশে **লাল বাক্স** দেখায়
- পেজের উপরে **সতর্কবার্তা** আসে

**লাল বাক্স দেখলে সেই এলাকার সংখ্যা বিশ্বাস করবেন না।**

### অন্যান্য সীমাবদ্ধতা

- কার্বনের হিসাব **আনুমানিক**। মাটি খুঁড়ে মাপা হয়নি, গড় মান ব্যবহার করা হয়েছে।
- এটি **কার্বন ক্রেডিট নয়**, আর এর কোনো আর্থিক মূল্য দাবি করা হয় না।
- ভবিষ্যৎ চিত্র **পূর্বাভাস নয়**।
- কোনো নির্দিষ্ট জায়গায় ব্যবস্থা নেওয়ার আগে **মাঠে গিয়ে যাচাই** করা দরকার।
- ডেমোর জন্য **সজনেখালি বা জঙ্গলের জায়গা** বেছে নিন।

## ৯. সেটিংস ফাইল (.env) বোঝা

`backend\.env` ফাইলের গুরুত্বপূর্ণ লাইন:

| সেটিং | মানে | উদাহরণ |

| `GEE_PRIVATE_KEY_FILE` | key ফাইলের ঠিকানা (`backend` ফোল্ডার থেকে) | `secrets/gee-service-account.json` |
| `GEMINI_API_KEY` | Gemini AI-এর চাবি (ঐচ্ছিক) | — |
| `GEMINI_MODEL` | কোন Gemini মডেল | `gemini-2.5-flash` |
| `MONGODB_URI` | ডেটাবেসের ঠিকানা (ঐচ্ছিক) | ফাঁকা রাখলে ডেটাবেস ছাড়াই চলে |
| `CGMD_MANGROVE_MIN_FCC` | কত % ঢাকা হলে "ম্যানগ্রোভ" ধরা হবে | `50` |

`.env` বদলানোর পর **ব্যাকএন্ড বন্ধ করে আবার চালু করতে হবে।**

## ১১. সমস্যা হলে কী করবেন

| সমস্যা | কারণ | সমাধান |
| :-- | :-- | :-- |
| পেজে লেখা "Cannot reach the analysis server" | ব্যাকএন্ড চালু নেই | ব্যাকএন্ড চালু করুন ([৪ নম্বর অংশ](#৪-প্রজেক্ট-চালানো--প্রতিদিন)) |
| হলুদ "Demo mode" দেখাচ্ছে | চাবি নেই বা ভুল | `backend\.env`-এ `GEE_ENABLED=true` আর key ফাইলের ঠিকানা দেখুন, তারপর ব্যাকএন্ড আবার চালু করুন |
| "Port 8000 already in use" | পুরোনো ব্যাকএন্ড চলছে | পুরোনো কালো উইন্ডো বন্ধ করুন, বা কম্পিউটার রিস্টার্ট করুন |
| "No usable Sentinel-2 images" | ওই সময়ে মেঘ বেশি | "ছবির সময়কাল" বাড়ান (১২০–১৮০ দিন), বা অন্য তারিখ বাছুন |
| "Pick dates at least 180 days apart" | দুই তারিখ খুব কাছাকাছি | ফারাক বাড়ান |
| বিশ্লেষণ অনেকক্ষণ চলছে | লাইভ মোডে প্রথমবার স্বাভাবিক | ২–৩ মিনিট অপেক্ষা করুন। বড় ব্যাসার্ধে আরও বেশি লাগে |
| "User memory limit exceeded" | এলাকা খুব বড় | ব্যাসার্ধ কমান |
| লাল "এলাকা যাচাই" বাক্স | মডেল ও CGMD মিলছে না | ওই এলাকার সংখ্যা বিশ্বাস করবেন না ([৮ নম্বর অংশ](#৮-ফলাফল-কতটা-বিশ্বাসযোগ্য-জরুরি-সতর্কতা)) |
| Gemini-র লেখা আসছে না | চাবি নেই, বা লেখা যাচাইয়ে বাতিল | স্বাভাবিক; সাধারণ টেমপ্লেট দেখানো হয় |

## ১২. শব্দকোষ

| শব্দ | সহজ মানে |
| :-- | :-- |
| **ম্যানগ্রোভ** | নোনা জলে জন্মানো বন (সুন্দরী, গরান, গেঁওয়া ইত্যাদি) |
| **ব্লু কার্বন** | সমুদ্র-উপকূলের বনে (যেমন ম্যানগ্রোভ) জমা কার্বন |
| **হেক্টর** | জমির মাপ: ১০০ মি × ১০০ মি = প্রায় ৭.৫ বিঘা |
| **Mg C** | মেগাগ্রাম কার্বন = ১ টন কার্বন |
| **CO₂e** | কার্বন ডাই-অক্সাইডের সমতুল্য পরিমাণ |
| **Sentinel-2** | ইউরোপীয় মহাকাশ সংস্থার উপগ্রহ, যা পৃথিবীর ছবি তোলে |
| **Google Earth Engine** | Google-এর সার্ভার, যেখানে উপগ্রহ ছবির বড় হিসাব চলে |
| **CGMD** | বিজ্ঞানীদের বানানো বিশ্বের ম্যানগ্রোভ ম্যাপ (১৯৮৪–২০২৩), মডেলের "শিক্ষক" |
| **Random Forest** | অনেকগুলো সিদ্ধান্ত-গাছের দল; সবাই ভোট দিয়ে উত্তর ঠিক করে |
| **NDVI** | গাছ কতটা সবুজ ও ঘন তার সূচক |
| **NDWI** | জল কতটা আছে তার সূচক |
| **পিক্সেল** | ছবির সবচেয়ে ছোট বর্গ (এখানে ১০ মি × ১০ মি) |
| **নির্ভুলতা (accuracy)** | ১০০টি পরীক্ষার মধ্যে মডেল কতটা ঠিক বলেছে |
| **কাপ্পা (kappa)** | আন্দাজে ঠিক হওয়া বাদ দিয়ে নির্ভুলতা (১ = নিখুঁত, ০ = আন্দাজের সমান) |
| **IPCC** | জাতিসংঘের জলবায়ু বিজ্ঞানীদের সংস্থা |
| **Tier 1** | IPCC-র সবচেয়ে সাধারণ (গড় মানভিত্তিক) হিসাব পদ্ধতি |
| **± পরিসর** | আসল মান সম্ভবত এই সীমার মধ্যে আছে |
| **API** | ওয়েবসাইট আর সার্ভারের মধ্যে কথা বলার পথ |
| **ব্যাকএন্ড / ফ্রন্টএন্ড** | সার্ভার অংশ (হিসাব করে) / ওয়েবসাইট অংশ (দেখায়) |
